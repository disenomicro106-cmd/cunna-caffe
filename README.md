# CUNNA Immersive Web V7

Esta versión conserva la experiencia anterior y ajusta únicamente la corriente 3D del footer:

- Más granos y tamaño ligeramente mayor.
- Profundidad con enfoque/desenfoque cinematográfico mediante BokehPass.
- Algunos granos se separan orgánicamente del borde de la espiral para evitar una forma perfecta.
- Cada grano conserva rotación y velocidad individual.
- Mouse y touch generan una perturbación mucho más fuerte, permitiendo arrastrar/desordenar la corriente.
- Después de detener el mouse/dedo, los granos regresan lentamente a su trayectoria.
- Material con más brillo/specular y clearcoat.

## Secuencia del Hero
La web busca 753 frames en `assets/secuencia 1/` con nombres `Comp 1_00000.png` ... `Comp 1_00752.png`.
No se incluyen los PNG de la secuencia en este ZIP: coloca tu carpeta existente dentro de `assets/`.

## Ejecutar
Usa un servidor local para que los módulos ES y la carga del GLB funcionen correctamente.
